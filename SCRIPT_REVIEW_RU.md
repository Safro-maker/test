# Исправления Assets/Scripts

Дата: 26 октября 2026 года. Проект импортирован из `strivingatt/badnorthproto`, коммит `ef24ed70c622c64cd649a58874fe01493eed3b5c`.

Все семь проблем предыдущей проверки исправлены в коде.

| Проблема | Исправление |
| --- | --- |
| Повторное E создаёт перекрывающиеся волны и пропускает паузу | E вызывает `StartFirstWave()`. Повторный запуск активной волны и обход положительного таймера запрещены. |
| Пауза 0 останавливает автоматические волны | Отдельный флаг ожидания позволяет запустить следующую волну при нулевой паузе. Отрицательная пауза трактуется как нулевая. |
| Неудачный спавн засчитывается как пройденная волна | `SpawnWave()` возвращает число созданных врагов. Номер меняется только при ненулевом результате. Автоматический запуск при неудаче повторяется через секунду без лечения игрока и увеличения номера. Пустой объект отряда удаляется. |
| Пращник останавливается за препятствием | ИИ и выстрел используют общую проверку дальности и линии видимости из произвольной позиции. Камни и живые юниты перекрывают выстрел; сам стрелок не мешает оценке будущей позиции. |
| Пустой или недоступный путь оставляет старую корутину | Предыдущее движение отменяется до проверки нового пути. Пустой/недоступный путь останавливает юнита в его логической клетке и восстанавливает регистрацию на сетке. |
| Боевые кулдауны отстают при низком FPS | Обрабатываются накопленные тики, до 64 за кадр; остаток времени сохраняется. Неположительный интервал ограничен 0.01 с, NaN/Infinity заменяются на 0.1 с. |
| Юниты проходят через новый камень на пути | Перед шагом и после каждого кадра движения проверяются клетка и углы диагонали. Игрок и ИИ останавливаются у нового препятствия; ИИ освобождает резерв цели и может построить новый путь. Для игрока требуется новый приказ. |

Дополнительно размер блока спавна ограничен размером сетки; завершившиеся синхронно корутины не оставляют ложную ссылку на активное движение. Игрок больше не телепортируется к переданной цели, если она не совпадает с последней клеткой предоставленного пути.

Калькулятор Python, его тесты, кеш и правила Python в `.gitignore` удалены. `README.md` содержит инструкции для Unity.

## Запуск тестов в Unity

Открыть проект в **Unity 6000.6.5f1**, дождаться импорта пакетов. Открыть **Window → General → Test Runner → PlayMode** и запустить `BadNorth.RegressionTests` / `RegressionTests` в чистой тестовой сцене. Тесты обращаются к существующим скриптам через reflection, чтобы не переносить их из Assembly-CSharp и не менять ссылки префабов.

После тестов запустить `Assets/Scenes/SampleScene.unity`: E должен запускать только первую волну, остальные — автоматически. Проверить перестроение отряда, стрельбу пращника и постановку камня перед движущимися игроком и врагом. При постановке препятствия игрок останавливается, враг ищет новый путь.

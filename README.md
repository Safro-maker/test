# Калькулятор на Python

Консольный калькулятор на Python 3.10 или новее. Сторонние библиотеки не нужны.

## Запуск

```sh
cd /workspace/test
python3 calculator.py
```

Введите выражение и нажмите Enter:

```text
> (2 + 3) * 4
= 20
> 7 / 2
= 3.5
> выход
До свидания!
```

Поддерживаются `+`, `-`, `*`, `/`, скобки, отрицательные и дробные числа.
Для дробей используйте точку, например `1.5 + 2.25`.
Для выхода введите `выход`, `exit` или `quit`, либо нажмите Ctrl+D / Ctrl+C.
Ошибки ввода и деление на ноль не прерывают работу калькулятора.
Выражения ограничены 200 символами и разбираются без `eval`.

## Проверка

python3 -m unittest -v

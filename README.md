# Bad North Prototype

Прототип тактической игры на Unity. Исходный проект: [strivingatt/badnorthproto](https://github.com/strivingatt/badnorthproto).

Откройте корень репозитория через Unity Hub в Unity **6000.6.5f1**, дождитесь импорта пакетов и запустите `Assets/Scenes/SampleScene.unity`.

- ЛКМ — выделение отряда; повторное нажатие и перетаскивание — формация.
- E — запуск первой волны; следующие запускаются автоматически.
- ПКМ — вращение камеры, короткий клик — отмена выделения/формации.
- Колесо мыши — приближение; B + ЛКМ — камни; B + 1–5 — размер камня.
- T — встроенная проверка формаций.

Исправления и ограничения проверки описаны в [SCRIPT_REVIEW_RU.md](SCRIPT_REVIEW_RU.md).

Небольшой учебный проект для экспериментов с тактическими механиками.
Пусть каждая новая идея становится шагом к интересной игре!
